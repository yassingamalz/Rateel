# 10. Marketing e pubblicazione

## Google Play

Fonte: [Publishing Rattil Tajweed Learning App to Google Play](https://claude.ai/chat/aedc6338-9a43-4620-9767-e11705e021a8).

- Account Play Console (25$ una tantum), nome proposto nel listing "Rattil - رَتِّلِ", lingua di default araba, categoria Education, gratuita.
- Build: `npm run build:android` (build Angular di produzione, asset Capacitor, `fix-icons.js`, sync Android), poi App Bundle firmato.
- Stato: closed testing approvato. Un'app in closed testing non compare nella ricerca pubblica; per renderla cercabile serve una release di produzione e una nuova revisione. Link diretto: `https://play.google.com/store/apps/details?id=com.novavista.rattil`.

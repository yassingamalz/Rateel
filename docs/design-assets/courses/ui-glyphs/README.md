# Rateel Courses — 4 UI glyphs

All four SVG files are independent, editable and use `viewBox="0 0 64 64"`, `fill="currentColor"`, filled paths only, 4 px minimum canvas padding, no filters or backgrounds.

- lock.svg — closed-course lock (shackle, rounded body, transparent keyhole).
- star.svg — slightly softened beginner-level star.
- play.svg — active-course play triangle with rounded corners.
- check.svg — completed-course rounded check mark.

Use CSS `color: #F2B623` for gold or `color: #F4EBD7` for ivory. The glyphs inherit currentColor.

`rateel_ui_glyphs_preview.png` is a 1200×340 raster preview on #023328, not part of the SVG assets.

The shapes are careful vector reconstructions from the small glyphs shown in REF-03 rather than extracted source paths.

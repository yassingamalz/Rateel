# Screen 29 — profile proposal

Landscape Flutter profile using the established screen 14 background, Arabic Cairo typography,
gold dividers and the existing leaderboard portrait. The profile is reachable through the settings
header and the preview APK starts directly on it. The return button returns to the app.

The displayed user, score, lessons and rank are the existing leaderboard demo data. The streak
uses the daily challenge demo notifier. The screen labels these as demo data. Level, account editing,
points history and badges require real data and are left for a later implementation.

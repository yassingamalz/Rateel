COME USARLI
-----------
1. In ogni richiesta allega come IMMAGINI DI RIFERIMENTO:
   - REF-A = la "مكتبة الأيقونات" (libreria icone fatta con ChatGPT)
   - REF-B = lo sfondo con l'arco e i reticoli negli angoli
   - REF-C = lo screenshot della lezione (schermata con il versetto)
   (per il personaggio, dalla sezione 1.2 in poi allega anche il foglio
   del personaggio generato in 1.1 = REF-D)
2. Incolla prima il BLOCCO STILE, poi il prompt dell'asset.
3. UN asset per richiesta. Se il risultato non è uguale allo stile,
   rispondi: "Match REF-A more closely: same gold, same line weight, same soft shadow."
4. SFONDO: Nano Banana non fa vera trasparenza. Per tutti gli elementi
   (non per gli sfondi) chiediamo un fondo MAGENTA pieno #FF00FF:
   lo rimuovo io con precisione. Non serve scontornare.
5. Scarica alla massima risoluzione e rinomina col NOME FILE indicato.
   Mandami tutto anche in un unico zip.

BLOCCO STILE (incollalo all'inizio di OGNI prompt)
---------------------------------------------------------------------
Use the attached reference images as the strict style guide. Match REF-A
exactly: premium Islamic educational app UI, deep emerald green (#043226,
#02271E) with warm metallic gold (#F7BC15, highlights #FFD95A, shadows
#B5850A) and soft cream (#F6EBCB). Clean vector-like illustration, smooth
rounded line work with the same stroke weight as REF-A, subtle soft drop
shadow below (light from top), very gentle inner glow on gold, no harsh
gradients, no photorealism, no 3D render look, no text unless requested,
no watermark, no human faces. Centered subject with generous padding.
Background: solid flat pure magenta #FF00FF, perfectly uniform, no shadow
cast on the background, no vignette.
